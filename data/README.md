# Where does the data come from?

- **Source:** Antonio, N., de Almeida, A. and Nunes, L. (2019). Hotel booking demand datasets. _Data in Brief_, 22, 41 to 49. https://doi.org/10.1016/j.dib.2018.11.126
- **Licence:** CC BY 4.0, so every copy of your work cites the source above.
- **Copy used:** the TidyTuesday version of 11 February 2020, 119,390 bookings and 32 columns.
- **How to get it:** `python src/data.py` downloads it into this folder. The file is never committed; `.gitignore` keeps it out.
- **Before you trust a column:** read section 2 of the article, which says when each column was recorded.
